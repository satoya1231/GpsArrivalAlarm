# GPS到着アラーム

目的地の近くに入ったらバイブレーションと通知を出す Android アプリです。

## 実装済み
- 目的地の追加
- 目的地の変更
- 目的地の削除
- フォルダの作成・選択・削除
- 目的地のフォルダ分け
- 目的地一覧の並べ替え（上下移動・端末内保存）
- 目的地一覧の長押しスライド並べ替え
- 現在地を目的地の緯度・経度として入力
- 到着判定距離の設定（50m以上）
- Geofencing によるバックグラウンド到着判定
- 到着時のバイブレーション
- 到着時の通知
- 監視開始 / 停止
- 到着監視中の地図表示モード（現在地・目的地・残り距離の表示）
- 目的地到着時の連絡方法（通知 / 音 / バイブ）の選択
- 到着時の監視自動停止と確認画面
- 確認画面を閉じるまで音・バイブを継続
- 音を選択していてもマナーモード時はバイブに自動切り替え
- Android 14 以降でも確認画面まで到着アラームを継続
- 監視開始直後に範囲内の場合も即時に到着判定
- データの端末内保存（SharedPreferences + JSON）

## 開発環境
- Android Studio Quail 3 / 2026.1.3 相当
- Android Gradle Plugin 8.10.0
- Gradle 8.11.1
- compileSdk 36
- targetSdk 36
- minSdk 26
- Jetpack Compose BOM 2025.05.00

## 起動方法
1. Android Studio でこのフォルダを開きます。
2. SDK Manager で Android API 37 をインストールします。
3. Gradle Sync を実行します。
4. 実機を USB デバッグ接続して Run します。
5. 位置情報は「正確な位置情報」を許可してください。
6. バックグラウンド到着通知を使うため「常に許可」相当の位置情報権限も許可してください。
7. Android 13 以降では通知も許可してください。

## 注意
Geofence は端末・OSの省電力処理、GPS精度、Wi-Fi/基地局状況によって検知が遅れる場合があります。鉄道など高速移動で使う場合は、到着判定距離を 300〜1000m 程度に広げて実機確認してください。




## 地図から目的地を登録する機能（無料版）

目的地の追加・変更画面で「地図から選択」を押すと OpenStreetMap が開きます。
地図上の任意の場所をタップするとマーカーが移動し、「この場所を目的地にする」で緯度・経度が入力されます。

### APIキーは不要です

Google Maps SDK は使用していません。Google Cloud の登録や `MAPS_API_KEY` の設定は不要です。
地図表示には OpenStreetMap の地図タイルを利用します。

## 住所・駅名検索

地図画面上部の検索欄から、駅名・住所・端末が解決できる施設名を検索できます。
検索は Android 標準の `Geocoder` を利用するため、Google Places API の追加キーも不要です。

## 無料利用についての注意

このアプリは個人利用を想定しています。OpenStreetMap の公開タイルサーバーは無制限の無料配信サービスではありません。
多数のユーザーへ配布する場合は、OpenStreetMap のタイル利用ポリシーを確認し、専用のタイル配信サービスやセルフホストを検討してください。

## 403エラー対策（v1.1）

- OpenStreetMap地図タイルを `https://tile.openstreetmap.org/` に固定しました。
- 地図通信にアプリ固有User-Agentを設定しました。
- 地図上へ `© OpenStreetMap contributors` の帰属表示を追加しました。
- 目的地検索は Android 標準 Geocoder を使用し、Nominatim への直接アクセスを行いません。


## 1.2: 検索画面 403 対策

目的地検索で公開 Nominatim サーバーへ直接 HTTP アクセスする方式を廃止しました。
検索は Android 標準 `Geocoder` を使用するため、検索時の Nominatim HTTP 403 は発生しません。
検索サービスが端末で利用できない場合でも、OpenStreetMapをタップして目的地を直接選択できます。
地図表示は引き続きAPIキー不要です。

## 到着までの地図表示

監視を開始すると地図表示モードに切り替わり、現在地と目的地を OpenStreetMap 上に表示します。
現在地の更新に合わせて地図が追従し、到着すると地図表示は自動的に終了します。
