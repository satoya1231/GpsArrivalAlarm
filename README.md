# GPS到着アラーム

目的地の近くに入ったらバイブレーションと通知を出す Android アプリです。

## 主な機能

- 目的地の追加・変更・削除
- フォルダの作成・選択・削除、目的地のフォルダ分け
- 目的地一覧の並べ替えと端末内保存
- 現在地を目的地の緯度・経度として入力
- 地図上のタップや駅名・住所・施設名の検索による目的地選択
- 到着判定距離の設定（1m以上）
- Geofencing によるバックグラウンド到着判定
- 到着時のバイブレーションと通知
- 監視開始・停止
- 到着監視中の地図表示（現在地・目的地・残り距離・方位磁針）
- 到着時の連絡方法（通知・音・バイブ）の選択
- 到着時の監視自動停止と確認画面
- データの端末内保存（SharedPreferences + JSON）

## 地図について

地図表示には OpenStreetMap の地図タイルを利用しています。Google Maps SDK や Google Cloud の登録、APIキーは不要です。

目的地の追加・変更画面で「地図から選択」を押すと地図が開きます。地図上の任意の場所をタップし、「この場所を目的地にする」を押すと緯度・経度が入力されます。

検索は Android 標準の `Geocoder` を利用するため、Google Places API の追加キーも不要です。

OpenStreetMap の公開タイルサーバーは無制限の無料配信サービスではありません。多数のユーザーへ配布する場合は、[OpenStreetMap のタイル利用ポリシー](https://operations.osmfoundation.org/policies/tiles/)を確認し、専用のタイル配信サービスやセルフホストを検討してください。

## 起動方法

1. Android Studio でこのフォルダを開きます。
2. SDK Manager で必要なAndroid SDKをインストールします。
3. Gradle Syncを実行します。
4. 実機をUSBデバッグ接続してRunします。
5. 位置情報は「正確な位置情報」を許可してください。
6. バックグラウンド到着通知を使うため、位置情報のバックグラウンド利用も許可してください。
7. Android 13以降では通知も許可してください。

## 注意

Geofence は端末・OSの省電力処理、GPS精度、Wi-Fi/基地局状況によって検知が遅れる場合があります。鉄道など高速移動で使う場合は、到着判定距離を300〜1000m程度に広げて実機確認してください。
